# FleetRental — Sistema de Gestão de Locadora de Veículos

Sistema web completo (Desktop & Mobile) para administração de locadora de veículos, centralizando o controle de frota, clientes, contratos, recebimentos recorrentes, quilometragem projetada e manutenção preventiva inteligente.

## Como Executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor Back-end + Front-end em modo de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Acesse no navegador: `http://localhost:5173`
   - **Usuário inicial:** `admin`
   - **Senha inicial:** `admin123`

## Executar Testes Automatizados

```bash
npm test
```
